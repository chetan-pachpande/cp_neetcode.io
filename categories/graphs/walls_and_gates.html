Walls and Gates

Multi-source BFS ⏱ O(mn) time 💾 O(mn) space

Problem

Given rooms marked as empty rooms, walls, and gates, fill every empty room with the distance to its nearest gate.

Use INF for empty rooms, -1 for walls, and 0 for gates.

Input: INF,-1,0,INF / INF,INF,INF,-1 / INF,-1,INF,-1 / 0,-1,INF,INF
Output: each room gets nearest-gate distance

Intuition

All gates are distance 0, and every empty room wants the nearest one. Start BFS from all gates at once.

The first time BFS reaches a room is guaranteed to be the shortest path from any gate. Walls block movement; already-filled rooms are skipped.

Full Explanation

Walls and Gates is a nearest-source distance problem. If we run BFS separately from every room, we repeat work. Instead, put every gate into the queue first, as if every gate starts broadcasting distance zero at the same time.

When the BFS wave reaches an empty room, that wave is the nearest gate because BFS expands by distance. We write the distance into the room and continue expanding from there.
