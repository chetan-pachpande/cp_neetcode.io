Rotting Oranges

Multi-source BFS ⏱ O(mn) time 💾 O(mn) space

Problem

Each minute, every rotten orange makes its adjacent fresh oranges rotten. Return the minimum minutes until no fresh oranges remain, or -1 if impossible.

Input: 2,1,1 / 1,1,0 / 0,1,1
Output: 4

Intuition

All rotten oranges spread at the same time, so this is a breadth-first search starting from every rotten orange at once.

Process the queue level by level. One BFS layer equals one minute. When a fresh neighbor rots, decrement the fresh count and enqueue it for the next minute.

Full Explanation

Rotting spreads simultaneously, so a normal DFS would not model time correctly. Multi-source BFS does: put every initially rotten orange into the queue, count fresh oranges, then process the queue one layer at a time.

Each layer is one minute of spread. Whenever a fresh neighbor becomes rotten, it is added to the queue for a future layer. If all fresh oranges rot, the minute counter is the answer. If some fresh oranges remain unreachable, return -1.
