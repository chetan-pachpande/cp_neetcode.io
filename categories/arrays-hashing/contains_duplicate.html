Contains Duplicate

HashSet ⏱ O(n) time 💾 O(n) space

Problem

Given an integer array nums, return true if any value appears at least twice, and false if every element is distinct.

Input:  nums = [1,2,3,1]
Output: true
Input:  nums = [1,2,3,4]
Output: false

Intuition

Sorting would work in O(n log n), but we can trade a little memory for speed. A HashSet remembers everything we've seen with O(1) lookups.

Walk the array once. Before adding each number, ask the set: "seen this before?" The first yes is our duplicate — return immediately. If we finish the walk, everything was unique.

Full Explanation

We scan the array left to right while maintaining a HashSet of every value seen so far. At each element we first check membership: if the value is already in the set we have found a duplicate and return true immediately — no need to look any further. Otherwise we insert the value and continue.

Each element triggers at most one lookup and one insertion, both constant time on average, so the whole scan is linear. The set can grow to hold every element, giving linear space. This is the classic time-for-space trade against the O(n log n) sorting approach.
