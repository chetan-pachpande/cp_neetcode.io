Surrounded Regions

Border DFS ⏱ O(mn) time 💾 O(mn) space

Problem

Capture every region of Os that is fully surrounded by Xs by flipping those Os to Xs.

Any O connected to the border cannot be captured.

Input: XXXX / XOOX / XXOX / XOXX
Output: XXXX / XXXX / XXXX / XOXX

Intuition

Instead of searching for surrounded regions directly, find the regions that are definitely not surrounded: Os connected to the border.

Mark border-connected Os as safe. Then any remaining O must be enclosed, so flip it to X. Finally restore safe marks back to O.

Full Explanation

An O survives only if it can reach the border through other Os. So we run DFS from every border O and temporarily mark those cells as safe.

After safe cells are marked, the board has a simple rule: every remaining O is surrounded and flips to X; every safe mark changes back to O. This avoids checking each region for enclosure from the inside.
