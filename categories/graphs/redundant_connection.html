Redundant Connection

Union-Find ⏱ O(E α(V)) time 💾 O(V) space

Problem

A graph started as a tree, then one extra edge was added. Return the edge that creates a cycle.

Input: edges = [[1,2],[1,3],[2,3]]
Output: [2,3]

Intuition

Union-Find treats each connected component like an island with a representative root.

For each edge, if the endpoints are in different components, the edge safely connects two islands. If they already share a root, the new edge closes a loop and is redundant.

Full Explanation

Every accepted edge joins two previously separate components. Union-Find lets us ask whether two nodes already belong to the same component before adding an edge.

When an edge connects nodes that already share a root, there is already a path between them. Adding that edge creates the first cycle, so that edge is redundant.
