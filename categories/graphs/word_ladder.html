Word Ladder

BFS shortest path⏱ O(N · L · 26) time💾 O(N) space

Problem

Transform beginWord into endWord by changing one letter at a time, where every intermediate word must be in the word list. Return the shortest transformation length.

Input: hit → cog, words = [hot,dot,dog,lot,log,cog]
Output: 5

Intuition

Each word is a room. A doorway exists between two words that differ by exactly one letter. We need the shortest route from begin to end, so BFS is the natural tool.

Each BFS layer is one transformation length. The first time we see the end word, that layer gives the shortest ladder.

Full Explanation

Word Ladder is shortest path in an implicit graph. We do not build every edge upfront; from the current word, we try changing each character to every letter and keep only real dictionary words. BFS guarantees the first time we reach the target is the shortest transformation.
