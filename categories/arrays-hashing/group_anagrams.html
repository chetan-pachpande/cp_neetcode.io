Group Anagrams

HashMap of Buckets ⏱ O(n · k log k) time 💾 O(n · k) space

Problem

Given an array of strings strs, group the anagrams together. Answer may be in any order.

Input:  ["eat","tea","tan","ate","nat","bat"]
Output: [["eat","tea","ate"],["tan","nat"],["bat"]]

Intuition

All anagrams share one hidden property: sorting their letters produces the same string. "eat", "tea", and "ate" all sort to "aet".

That sorted string is a perfect bucket key. Sort each word's letters, use the result as a HashMap key, and drop the original word into that bucket. When we're done, the map's values are exactly the anagram groups.

O(n·k log k)
Time — sort each of n words of length k
O(n·k)
Space — all words stored in buckets

Full Explanation

The trick is finding a canonical form that is identical for all anagrams of a word and different for everything else. Sorting the word's letters gives exactly that: every anagram of "eat" sorts to "aet". We use this sorted string as a HashMap key.

For each word we sort its characters, look up the bucket for that key — creating it if needed — and append the original word. Words that are anagrams of each other inevitably land in the same bucket. At the end, the map's values are the answer. With n words of average length k, sorting dominates: O(n times k log k) time, and O(n times k) space to hold the groups.
