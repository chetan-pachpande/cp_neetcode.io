Product of Array Except Self

Prefix / Suffix Products ⏱ O(n) time 💾 O(1) extra space

Problem

Given an integer array nums, return an array answer where answer[i] is the product of every element except nums[i]. Must run in O(n) without using division.

Input:  nums = [1,2,3,4]
Output: [24, 12, 8, 6]

Intuition

The product of everything except nums[i] is exactly (product of everything to its left) times (product of everything to its right). No division needed.

Pass 1, left to right: fill answer[i] with the running prefix product of everything before i. Pass 2, right to left: multiply in a running suffix product of everything after i. Two linear passes, one output array, no extra memory beyond a single running variable each time.

O(n)
Time — two linear passes

Full Explanation

We split the product except self into two halves: everything strictly to the left of index i, and everything strictly to the right. In the first pass we walk left to right, writing the running prefix product into the answer array before multiplying the current value in — so answer at i starts out holding the product of everything before it.

In the second pass we walk right to left with a running suffix product, multiplying it into the answer array at each index before folding the current value into the suffix. By the end, every index holds prefix times suffix, which is exactly the product of the whole array except that one element. Both passes are linear and only a single running variable is needed each time, giving O(n) time with no extra array beyond the output itself.
