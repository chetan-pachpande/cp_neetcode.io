Number of Connected Components

Union-Find⏱ O(E α(V)) time💾 O(V) space

Problem

Given n nodes and undirected edges, return the number of connected components.

Input: n = 5, edges = [[0,1],[1,2],[3,4]]
Output: 2

Intuition

Start with every node as its own island. Every edge that joins two different islands reduces the component count by one.

If an edge connects nodes already in the same component, it does not change the count.

Time — union each edge

Union-Find makes component counting visual: every node starts alone. Each successful union ties two separate groups together and lowers the count. Failed unions mean the edge stayed inside an existing group.
