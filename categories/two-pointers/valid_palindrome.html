Valid Palindrome

Two Pointers, Converging ⏱ O(n) time 💾 O(1) space

Problem

Given a string, determine if it's a palindrome after lowercasing and removing all non-alphanumeric characters.

Input:  s = "Was it a car or a cat I saw?"
Output: true

Intuition

A palindrome reads the same forwards and backwards, so its first and last characters must match, then its second and second-to-last, and so on, working inward.

Two pointers start at both ends. Skip past anything that isn't a letter or digit. Compare the two characters — mismatch means it's not a palindrome, return immediately. If the pointers cross without ever mismatching, every pair checked out.

Full Explanation

We first mentally normalize the string: lowercase every letter and treat only letters and digits as significant, ignoring spaces and punctuation. Rather than building a new cleaned string, we do this filtering on the fly with two pointers, one starting at the left end and one at the right.

At each step, we advance the left pointer forward past any character that isn't alphanumeric, and pull the right pointer backward past any non-alphanumeric character on that side. Once both pointers rest on real characters, we compare them. Any mismatch proves the string isn't a palindrome, so we return false immediately. If the pointers meet or cross while every comparison has matched, the string is a palindrome — every character had its mirror.
