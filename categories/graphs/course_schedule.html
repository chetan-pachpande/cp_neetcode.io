Course Schedule

Topological Sort ⏱ O(V + E) time 💾 O(V + E) space

Problem

Given numCourses and prerequisite pairs [course, prerequisite], decide if it is possible to finish all courses.

A cycle means some courses wait on each other forever, so finishing is impossible.

Input: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
Output: true

Intuition

Think of each course as locked behind prerequisite keys. Courses with indegree 0 are unlocked and can be taken immediately.

Taking a course removes its outgoing prerequisite edges. If that unlocks another course, add it to the queue. If every course gets taken, no cycle exists.

Full Explanation

Topological sort turns prerequisites into a queue of unlocked courses. Every course tracks its indegree, the number of prerequisites still blocking it.

When we take a course, we remove its edges to dependent courses. If a dependent course's indegree drops to zero, it becomes unlocked. A cycle keeps at least one course locked forever, so the final taken count reveals whether all courses can be finished.
