Valid Anagram

Frequency Count ⏱ O(n) time 💾 O(1) space — 26 letters

Problem

Given two strings s and t, return true if t is an anagram of s — the same letters rearranged.

Input:  s = "anagram", t = "nagaram"
Output: true
Input:  s = "rat", t = "car"
Output: false

Intuition

Two strings are anagrams exactly when every letter appears the same number of times in both. So we don't compare orderings — we compare letter counts.

One clever pass: for each position, +1 for the letter in s and −1 for the letter in t. Anagrams cancel perfectly — every counter ends at zero. Any non-zero counter is a mismatch.

Full Explanation

If the lengths differ the strings can't be anagrams, so we exit early. Otherwise we keep one counter per letter of the alphabet. Walking both strings simultaneously, each letter of s increments its counter and each letter of t decrements its counter.

If the strings are true anagrams, every increment is matched by a decrement and all twenty-six counters finish at zero. A final sweep over the counters confirms this: any non-zero value means one string has more of that letter than the other, and we return false. The pass over the strings is linear, and the counter array is constant size, so this runs in O(n) time with O(1) extra space.
