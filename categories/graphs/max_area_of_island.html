Max Area of Island

DFS component size ⏱ O(mn) time 💾 O(mn) space

Problem

Given a binary grid, return the maximum area of an island. The area is the number of land cells in one connected component.

Connections are horizontal and vertical only. If there is no land, return 0.

Input: 11000 / 11010 / 00111 / 00000
Output: 4

Intuition

This is the same connected-component traversal as Number of Islands, but instead of counting components, we measure each component.

Whenever a fresh land cell appears, DFS returns the size of that island: 1 for the current cell plus the areas from its four neighbors. Track the largest return value.

Full Explanation

For every cell, we only care about unvisited land. Starting DFS from that land cell measures the connected component it belongs to. The DFS marks each land cell visited and contributes one to the area, then recursively adds the areas from the four neighbors.

The outer scan compares each finished island area with the best area seen so far. Water and already visited cells return zero, which naturally stops the recursion at boundaries and prevents double-counting.
