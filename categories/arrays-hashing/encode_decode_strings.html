Encode and Decode Strings

Length-Prefix Encoding ⏱ O(n) time 💾 O(n) space

Problem

Design an algorithm to encode a list of strings into a single string, and decode that string back into the original list. Words may contain any character, including delimiters like commas.

Input:  ["neet","code","love","you"]
Encoded: "4#neet4#code4#love3#you"
Decoded: ["neet","code","love","you"]

Intuition

A simple separator like a comma breaks if a word contains a comma. The fix: prefix each word with its own length so the decoder always knows exactly how many characters to read next — no ambiguity possible.

Encode each word as length # word and concatenate. To decode, walk the string: read digits until # to get the length, then read exactly that many characters as the next word. Repeat until the string is exhausted.

O(n)
Time — each char visited once, both ways
O(n)
Space — the encoded string

Full Explanation

The core problem with a naive separator like a comma is that a word could itself contain a comma, making the encoded string ambiguous. We solve this by prefixing every word with its own length followed by a delimiter character, typically a hash sign. Because the decoder always knows how many characters to consume once it reads the length, the delimiter itself never needs to be searched for inside the word — only before it.

To encode, we simply concatenate length, hash, and word for every string in the list. To decode, we walk the combined string with a pointer: read digits until we hit the hash sign, parse those digits as the next word's length, then read exactly that many characters as the word, and advance the pointer past it. Repeating this until the pointer reaches the end recovers the original list exactly, in O(n) time for a combined string of length n.
