Number of Islands

Grid DFS flood fill ⏱ O(mn) time 💾 O(mn) space

Problem

Given an m x n grid of '1's for land and '0's for water, return the number of islands.

An island is formed by connecting adjacent land horizontally or vertically. Water surrounds the grid boundary.

Input: 11110 / 11010 / 11000 / 00000
Output: 1

Intuition

Scan every cell. When we find unvisited land, we have found the start of a new island.

From that cell, DFS marks the entire connected component as visited so none of those land cells can start another island later. Each grid cell is processed at most once.

Full Explanation

Number of Islands is connected-component counting on a grid. The outer loops search for cells that can start a new component: land that has not been visited yet. When such a cell appears, we increment the answer and run DFS from it.

The DFS checks boundaries, water, and already visited cells before marking land as visited. Then it explores the four cardinal neighbors. That one DFS call consumes the entire island, so later outer-loop scans skip those cells. Since no cell is visited more than once, the total work is proportional to the grid size.
