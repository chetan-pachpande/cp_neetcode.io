Valid Sudoku

HashSets per Row/Col/Box ⏱ O(81) time 💾 O(81) space

Problem

Determine if a 9×9 Sudoku board is valid. Only the filled cells need to be validated: each row, column, and 3×3 sub-box must contain each digit 1-9 at most once. The board doesn't need to be solvable, just consistent so far.

Input:  partially filled 9×9 board
Output: true if no row/col/box has a repeated digit

Intuition

Three independent constraints, three independent HashSets. For every filled cell (r, c) with digit d, we need three memories: "has row r seen d?", "has column c seen d?", and "has box ⌊r/3⌋·3 + ⌊c/3⌋ seen d?"

Scan the board once, left to right, top to bottom. At each filled cell, check all three sets — if any already contains d, the board is invalid immediately. Otherwise add d to all three and move on.

Full Explanation

We keep one HashSet per row, one per column, and one per three by three box — twenty seven sets in total, each capable of holding the digits one through nine. The board index of a box is computed as row divided by three, times three, plus column divided by three, using integer division, which maps every cell to one of nine boxes.

We scan the board once. Empty cells are skipped. For every filled cell we check whether its digit is already present in the corresponding row set, column set, or box set. If any of the three already contains it, we have found a duplicate and the board is invalid. Otherwise we insert the digit into all three sets and continue. Because the board size is fixed at eighty one cells, this runs in constant time and constant space relative to any larger input.
