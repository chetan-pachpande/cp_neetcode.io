Clone Graph

DFS + HashMap ⏱ O(V + E) time 💾 O(V) space

Problem

Given a reference to a node in a connected undirected graph, return a deep copy of the graph.

Each node contains a value and a list of neighbor nodes. The clone must use entirely new nodes with the same connections.

Input: 1: [2,4], 2: [1,3], 3: [2,4], 4: [1,3]
Output: deep copy of the same adjacency structure

Intuition

A graph can contain cycles, so recursive cloning needs memory. A HashMap from original node to cloned node prevents infinite recursion and preserves shared edges.

When DFS sees a node for the first time, create its clone and store it immediately. Then recursively clone each neighbor and append those cloned neighbors to the current clone.

Full Explanation

Clone Graph is a deep-copy problem with cycles. The map is the core idea: it records which original nodes already have cloned counterparts. That lets DFS return an existing clone when a cycle points back to a previously visited node.

For a new node, create a clone before cloning its neighbors. Storing the clone immediately is what breaks cycles. Then each neighbor is cloned recursively and added to the clone's neighbor list. By the time DFS returns to the start node, every reachable node and edge has an independent copy.
